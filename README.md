# MegaBit Wifi

Arabic and English guides to Wi-Fi, routers, connected devices, and network tools for the MegaBit Wifi Android app.

- Google Play: https://play.google.com/store/apps/details?id=com.albahnabwi.megabitpro
- Website: https://nexorastudiodevv-ctrl.github.io/MegaBit-/
- Sitemap: https://nexorastudiodevv-ctrl.github.io/MegaBit-/sitemap.xml

## Publishing

The static site is deployed from the `main` branch by `.github/workflows/pages.yml`.
In the repository settings, set **Pages → Build and deployment → Source** to **GitHub Actions**.

The site includes Arabic/English language alternates, canonical URLs, and a sitemap. Search engines decide independently when and where to index pages; publishing does not guarantee rankings.
